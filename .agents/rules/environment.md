# Regra de Restrição de Ambiente Local

- Esta máquina é um Mac pessoal de desenvolvimento e edição de código.
- NUNCA execute scripts bash (.sh), comandos de execução do projeto (uvicorn, python app, etc.), instaladores ou serviços nesta máquina.
- Toda execução é realizada exclusivamente pelo usuário no servidor Nobara Linux via SSH.
- No Mac, realize apenas edição de arquivos e operações de Git (status, diff, add, commit).
